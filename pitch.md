# Detach: Cursor for Your Entire Mac

## Overview

The first generation of AI products brought intelligence into chat windows. As AI agents become more capable, the bottleneck is no longer intelligence. It is access, context, and execution.

Today, users constantly switch between AI apps, browser tabs, terminals, models, and workflows. Most AI desktop products still follow the same structure: a chat composer trapped inside an application, a conversation sidebar, and separate workspaces for different tasks.

Detach removes that boundary.

Detach is a native macOS workspace for AI agents that stays available everywhere a user works. With one hotkey, users can summon an agent from any app, give it a task, and let it continue working in the background while its live status appears in the Mac notch.

## The Problem

AI usage is fragmented.

Users often pay for several AI subscriptions because different products are better suited to different tasks:

- Codex for coding
- Claude for research and writing
- Grok for search and reasoning
- ChatGPT for general-purpose work

Cursor solved this problem for developers by offering access to multiple models inside one unified coding product. But no equivalent exists for the rest of the computer.

Users still have to switch between AI apps, repeatedly copy and paste context, manage separate conversation histories, and learn multiple interfaces.

There is also no standard way for agents to safely complete authenticated workflows. Tasks such as logging in, creating accounts, accessing private services, or completing sensitive actions require credentials that users should never expose directly to an AI model.

## The Solution

Detach brings the unified, model-agnostic experience of Cursor to the entire Mac.

Instead of placing the agent inside another full-screen chat application, Detach compresses the experience into a lightweight composer that can be opened from anywhere.

A user can ask Detach:

> Open Instagram and reply to the comments on my latest post.

The agent can then work across the browser and native macOS applications using the tools and context available on the user’s computer.

Detach currently works with the agent subscriptions users already pay for, including Codex, Claude Code, and Grok. It also connects agents to the growing MCP ecosystem and native macOS automation, allowing them to complete tasks across coding, research, communication, file management, browser workflows, and everyday applications.

The long-term vision is to offer one unified AI subscription for every workflow, similar to Cursor’s multi-model experience for coding, but extended across the entire computer.

## Secure Agent Credentials

Detach has also developed a credential vault designed specifically for AI agents.

The vault allows agents to complete authenticated actions such as logins and sign-ups without revealing the user’s actual password to the model.

This creates a secure permission and identity layer between the user, the agent, and the applications it operates. This infrastructure will become increasingly important as agents perform more sensitive and autonomous tasks.

## Why Now

AI models are rapidly becoming capable of completing multi-step tasks, operating browsers, writing code, and interacting with software.

However, the desktop is still organised around isolated applications rather than agents. Every AI company is building its own interface, workflow, and closed environment.

Detach is building the layer that connects agents to the user’s entire computer.

The desktop was designed around apps. We believe the next generation of computing will be organised around agents.

## Traction

The product is currently free while we validate usage patterns, refine the core experience, and develop the right monetisation model.

Early benchmarking on a subset of browser-use benchmark tasks produced a 100% completion rate. We plan to expand this into a larger and more rigorous benchmark suite.

## Business Model

Detach plans to introduce a freemium subscription model.

The free tier will allow users to connect and use their existing agents through the core Detach experience.

Paid plans are expected to include advanced agent workflows, higher automation limits, persistent context, premium integrations, credential vault capabilities, scheduled tasks, and access to multiple models through one unified subscription.

Future team plans could include shared workflows, organisation-level permissions, collaborative agents, and centralised security controls.
